# French Structure Lab — v0.3.0

A1–C2フランス語学習用の、iPhone対応・オフライン利用を想定した静的PWAです。**18ユニット・計108問**（v0.2から教材の問題数は変えていません）。仏検2級向け問題、10文の詳細文構造分析、7動詞×6時制・法の活用比較も収録しています。問題解答 → 文法構造理解 → 振り返り → 再会という流れを重視しています。

## v0.3 新機能 — Chinese Structure Labの学習記録を参考に

- **再会と理解の変化**：問題ごとに最近の回答を「× / ✓」で表示。誤答後に正答があった履歴を示します（習得・CEFRレベル認定を意味しません）。
- **文法分野集中練習**：そのレベルで誤答のある文法分野を選んで練習できます。
- **理由付き次回提案**：復習期限、苦手印、直近の誤答、新出教材を優先し、候補ごとの理由を表示します。提案はルールベースで、AI推定ではありません。
- **学習終了時に集計**：問題解答イベントから、セッションの正誤・誤答分野・次回の推薦IDを集計してセッションに保存します。解答中は履歴を追加するだけにして、終了時に分析します。
- **AI分析用・詳細学習データJSON**：各問題の時系列回答、解説、学習進捗、苦手印、セッション振り返りを外部で分析しやすい形式で出力します。**アプリ自体はAI APIに送信しません。**
- **文字拡大**：ヘッダーのA＋で大きな文字に切り替え、設定を端末内に保存します。

## 継続して使える機能

## セットアップ

`index.html`をMacで開くと、静的画面を試せます。GitHub Pagesで公開してSafariのホーム画面に追加する手順は **[DEPLOY_GITHUB_PAGES.md](./DEPLOY_GITHUB_PAGES.md)** を参照してください。

サーバーで確認するときは、このフォルダー内で `python3 -m http.server 8000` を起動し、`http://localhost:8000` へアクセスします。PWAオフライン機能はService Workerが許可されるHTTPS / localhostで利用します。

## 保存・プライバシー・移行

- GitHub Pagesに公開されるのはアプリのコードと教材であり、あなたの学習履歴ではありません。すべての学習記録はブラウザの`localStorage`にあります。
- v0.2の保存キー`french-structure-lab:v1:`を維持。**同じブラウザ・同じURLならv0.2の学習履歴を引き継ぐ**設計です。v0.1の問題別集計も引き継げます。ただし過去の回答イベントは遡って生成されません。
- v0.2の完全バックアップJSONをv0.3に復元可能。v0.3のバックアップは`schemaVersion:"3.0"`です。
- ブラウザやURLが変わると自動的に学習記録は移りません。移す前に完全バックアップJSONをiCloud Driveなどへ保存し、移行先で復元してください。復元は現地の学習データを**置換**します。
- iCloud自動同期、ローカルAI分析、Listening/Reading/Writing/Speakingの正式なCEFR能力判定は未実装です。
- 「AI分析用JSON」は個人的な学習メモを含む場合があります。共有先に注意してください。
- localStorageは容量に制限があるため、長く使う場合はJSONバックアップを定期的に取ってください。

## v0.4.0 — 仏検 4級〜1級の筆記・文法対策（2026-11-05）

A1〜C2の既存教材（18ユニット・108問）と復習・文章分析は残したまま、**新しい「仏検対策」入口**を追加しました。メイン画面上部の「仏検対策」から `exam.html` を開きます。

- 対象：4級、3級、準2級、2級、準1級、1級（**各12問、計72問の独自問題**）。既存108問と合わせて180問。
- 四択、語形の記入、文の書き換え（記述は模範解答と比較し自己採点）。級に応じて出題形式を変えます。
- 「今日の演習」「文法項目ごとの集中練習」「誤答・期限の復習」「本番風の選択式演習（解説を最後に表示）」を用意。
- 学習履歴は問題別・級別・文法分野別に保存。誤答→正答の変化、28日間の学習、級ごとの正答状況を表示。CEFRの進捗データとは分離。
- `exam.html`から仏検だけの履歴CSV・分析JSON・バックアップJSONを出力可能。
- メイン画面の**完全バックアップJSON**（schemaVersion 4.0）にも仏検データを収録。v0.3など古いバックアップを復元するときは、バックアップに含まれない現在の仏検履歴は保持します。
- 既存のlocalStorage保存キーは維持。iCloud自動同期やクラウド保存は行わず、バックアップファイルを手動で保存・復元します。

**重要：** この72問は仏検の試験内容・文法分野を参考に独自作成した初期教材です。公式過去問ではなく、各級の全分野・試験時間・配点を網羅するものではありません。現段階では合格可能性の予測機能はありません。時事・長文・語彙・ディクテ・聴き取り・面接の試験対策は別途拡張が必要です。

仏検（APEF）公式の試験形式：https://apefdapf.org/dapf/info/examens

APEFの過去問題サンプル：https://apefdapf.org/dapf/presentation/exemples

CEFRとの対応は「およそ」であり、一対一対応の認定ではありません。なお公式の対応表では4級に明確なCEFRレベルを割り当てていないため、本アプリでは「A1基礎」と便宜的に表示します。
